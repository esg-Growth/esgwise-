# ESGwise — AI-Powered ESG Assessment Platform

ESGwise is a modern, AI-driven platform designed to simplify ESG (Environmental, Social, and Governance) assessments for startups and SMEs in the MENA region. Aligned with **GRI Standards**, the platform provides actionable insights and professional reporting to help businesses achieve sustainability excellence.

## 🚀 Key Features

- **AI-Driven Data Extraction**: Automatically extract ESG KPIs from PDF reports, invoices, and energy bills using Gemini Pro.
- **GRI-Aligned Assessment**: Comprehensive questionnaire covering Environmental, Social, and Governance pillars.
- **Dynamic ESG Scoring**: Real-time scoring and rating system with gap analysis.
- **Professional Reporting**: Generate investor-ready PDF reports and interactive roadmaps.
- **Public Verification**: Issue cryptographically verifiable ESG certificates for stakeholder transparency.
- **AI Assistant**: Site-wide intelligent assistant to guide users through GRI standards and sustainability best practices.
- **Multi-lingual Support**: Full English and Arabic support (RTL).

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Database**: SQLite (better-sqlite3)
- **AI Engine**: Google Gemini 1.5 Pro/Flash
- **Styling**: Vanilla CSS (Premium Glassmorphism Design)
- **Hosting**: Firebase Hosting

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/esg-Growth/esgwise-
   cd esgwise
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env.local` file:
   ```env
   GEMINI_API_KEY=your_google_ai_key
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Access the platform**:
   Open [http://localhost:3010](http://localhost:3010)
